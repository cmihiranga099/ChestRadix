# ChestRadix

**A Trustworthy AI System for Emergency Chest X-Ray Triage and Priority Decision Support**

A doctor uploads one frontal chest X-ray. ChestRadix detects findings from 14 chest conditions
(NIH ChestX-ray14) and returns a single priority level (IMMEDIATE, URGENT or ROUTINE) with the reason:
the detected finding that set the level, plus a Grad-CAM heatmap showing where the model looked.
It gives no treatment or clinical advice.

> **Research prototype. Not a medical device and not for clinical use.**

## Research focus

- Calibrated probabilities (temperature scaling, ECE)
- Faithfulness of Grad-CAM and Grad-CAM++ explanations (pointing game, IoU, deletion/insertion)
- A simple disease-based priority rule, evaluated against label-based reference priorities
- Queue simulation: FIFO versus priority ordering
- Rigorous evaluation: patient-level split, three seeds, bootstrap confidence intervals, ablations

## Setup

Requires Python 3.11 or newer.

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# Linux / macOS
source .venv/bin/activate

pip install --upgrade pip
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
```

Verify the installation:

```bash
python -c "import torch, torchvision, fastapi, streamlit; print(torch.__version__, torchvision.__version__)"
```

Model training runs on Kaggle (free GPU); everything else runs on a laptop CPU.
